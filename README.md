# Чисельне інтегрування методами ООП (Лабораторна робота №6, Варіант №6)

Код для наближеного обчислення визначених інтегралів трьома методами (середніх прямокутників, трапецій та Сімпсона) з автоматичним підбором кількості розбиттів за правилом Рунге.

---

## Структура проєкту

* **`integrators.py`** — бібліотечний модуль із реалізацією базового класу `BaseIntegrator` та трьох класів-нащадків для чисельного інтегрування.

* **`main.py`** — головний файл для запуску, у якому задано підінтегральну функцію Варіанта №6 та розрахунок для всіх методів.

---

## Встановлення та запуск

### Передумови
* Встановлено **Python 3.10** або новіша версія, стандартна бібліотека `math`.

## Вхідні дані та результат роботи

* **У програмі (`main.py`) потрібно вказати:**
  * підінтегральну функцію (`target_function`);
  * межі інтегрування (а - нижня межа, b- верхня межа);
  * бажану точність обчислення;


* **Після запуску відбудеться наступне:**
  * обчислення по черзі інтеграла кожним із трьох методів, подвоюючи кількість розбиттів n, доки оцінка похибки за правилом Рунге не стане меншою за задану точність;

  * виведення у термінал назву методу, межі відрізка, уточнене значення інтеграла (з округленням до 7 знаків), мінімальну кількість розбиттів, яка знадобилась, та оцінку похибки.

## Опис класів, методів та функцій

### `integrators.py`

* **`BaseIntegrator`** — базовий клас, який задає спільний механізм обчислення інтеграла для всіх підкласів. В ньому зазначено:

  * `__init__(self, func, a, b)` — приймає підінтегральну функцію `func` та межі `a`, `b`; перевіряє коректність меж і зберігає параметри в атрибути об'єкта.

  * `validate_bounds(a, b)` — статичний метод, що перевіряє умову `a < b`; якщо межі некоректні, виводить помилку `ValueError`.

  * `from_dict(cls, func, params)` — метод класу, що приймає функцію `func` і словник виду `{"a": 0.0, "b": 1.0}` та повертає новий екземпляр відповідного класу.

  * `integrate(self, n)` — метод, який має бути перевизначений у нащадках, для обчислення інтеграла на `n` відрізках, якщо ж такого знайдено не буде видасть помилку `NotImplementedError`.

  * `adaptive_integrate(self, eps=3e-5, initial_n=2)` — приймає бажану точність `eps` та початкову кількість розбиттів `initial_n`; обчислює інтеграл за правилом Рунге з екстраполяцією Річардсона і повертає кортеж `(I_yt, n_min, похибка)`, де I_yt - це результат обчислень.

  * `__str__(self)` — повертає текстовий опис у форматі: `"<Назва методу> на відрізку [a; b]"`.

* **Класи-нащадки (нащадки `BaseIntegrator`)**
  * Мають в собі містити `integrate(self, n)`.

  * **`RectangleIntegrator`** (`order = 2`) — обчислює інтеграл складеною формулою середніх прямокутників.

  * **`TrapezoidIntegrator`** (`order = 2`) — обчислює інтеграл складеною формулою трапецій.

  * **`SimpsonIntegrator`** (`order = 4`) — обчислює інтеграл складеною формулою Сімпсона (додатково перевіряє, щоб `n` було парним, бо це потрібно лише для цього варіанту обчислень)

### Модуль `main.py`

* **`target_function(x)`** — приймає число `x` і повертає значення підінтегральної функції.

* **`main()`** — створює список об'єктів усіх трьох інтеграторів, запускає цикл обчислень для заданої точності та друкує результати.
